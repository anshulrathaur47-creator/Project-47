# raw-videos

Original, untouched footage: phone clips, screen recordings, camera files.

- Never edit or overwrite files here. Edits happen in `projects/`, and finished videos go to `exports/`.
- Name files by date and subject, e.g. `2026-11-14_rooftop-night.mp4`.
- GitHub rejects single files over 100 MB. Keep very large clips out of git or compress them first.
